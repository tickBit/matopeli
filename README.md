# Matopeli (worm game)

A worm game for very young children. The worm doesn't move automatically, it has to be dragged from its head.

![matopeli](https://github.com/user-attachments/assets/39177a1c-a563-40cc-b6ca-3487ccffeaa0)

Created with React Native with Android in mind.


If you want to run this, but don't know how to run a React Native project, then please use a search engine...
